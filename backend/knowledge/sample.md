# Sample Website Knowledge Base

## Welcome to Our Website

Our website is a modern platform designed to help users achieve their goals efficiently.

## Features

### Dashboard
The dashboard provides an at-a-glance overview of all your key metrics, activities, and recent updates. You can customize the dashboard layout by dragging and rearranging widgets.

### User Management
Manage team members, roles, and permissions from the User Management section. Navigate to **Settings → Team → Members** to invite new users or modify existing roles.

### Analytics
Our analytics suite provides detailed insights into usage patterns, engagement metrics, and performance indicators. Reports can be exported in CSV, PDF, and Excel formats.

### API Access
We provide a RESTful API for integration with third-party services. API documentation is available at `/docs`. API keys can be generated from **Settings → API Keys**.

## Frequently Asked Questions

### How do I reset my password?
Click on "Forgot Password" on the login page. Enter your registered email address, and you will receive a password reset link within 5 minutes.

### Can I upgrade my plan at any time?
Yes! Navigate to **Settings → Billing → Change Plan** to upgrade or downgrade your subscription. Changes take effect immediately, and billing is prorated.

### How do I contact support?
You can reach our support team through:
- Email: support@ourwebsite.com
- Live chat: Available on every page (bottom right)
- Help Centre: help.ourwebsite.com

### What browsers are supported?
We support the latest versions of:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Apple Safari

### Is my data secure?
Yes. All data is encrypted at rest using AES-256 and in transit using TLS 1.3. We are SOC 2 Type II certified and GDPR compliant. Read our full security policy at `/security`.
